# RoomSync | 3101 Sage Operations

A lightweight, high-efficiency hotel operations management dashboard built for **Front Desk** and **Housekeeping** staff at **3101 Sage Rd**.

🌐 **Live Demo:** [https://rulloa1.github.io/3101sage/](https://rulloa1.github.io/3101sage/)

---

## ✨ Features

- **Dual Operating Modes**:
  - **Front Desk Mode**: Comprehensive room cards grid with instant status overview, floor filtering, and room inspection.
  - **Housekeeping Mode**: Mobile-first, high-contrast, giant touch targets designed for fast 1-tap operation on smartphones on floor rounds.
- **Bilingual Interface**: 1-click toggle between **English** and **Spanish (Español)** for seamless team coordination.
- **Real-Time Interactive Stats**:
  - Clean / Ready
  - In Progress (Cleaning)
  - Dirty / Vacant
  - Occupied
  - Maintenance / Do Not Disturb
  - *Click any stat badge to instantly filter the room grid!*
- **Search & Filter**:
  - Live search by Room number, Bed type (King, Queen, Suite), or notes.
  - Filter by floor (1st, 2nd, 3rd Floor, or All).
- **Quick Status Updates & Notes**:
  - Modal with fast status change buttons and custom room notes (e.g., "VIP checkout", "Check AC").
  - Toast confirmation notifications for instant feedback.
- **Local Persistence**: State automatically persists across sessions using browser `localStorage` with a 1-click "Reset Demo" button.
- **Accessible & Responsive**: Fully responsive from mobile devices to desktop monitors, with keyboard shortcuts (`Esc` to dismiss modal, `Enter` to save).
